# Contributing to Daily LeetCode Solutions

Thanks for wanting to contribute! This repo grows better with every contribution.

## How to add a new problem

1. Create a new folder using this format:
   ```
   ProblemNumber-Problem-Title
   ```
   Example: `3702-Longest-Subsequence-With-Non-Zero-Bitwise-XOR`

2. Inside the folder add:
   - `README.md` → problem description + approach + complexity
   - `Solution.java`
   - `Solution.py`
   - `Solution.cpp`
   - and as many other languages as you can

3. Update the main `README.md` table with the new problem.

## Code style

- Keep solutions clean and readable
- Prefer simple over clever when possible
- Always mention Time and Space complexity
- Use proper naming (no single letter variables unless very obvious)

## Pull Request process

1. Fork the repo
2. Create a new branch (`git checkout -b add-problem-xxxx`)
3. Commit your changes
4. Open a Pull Request

I will review it as soon as possible.

## Need ideas?

- Add more languages to existing problems
- Improve explanations
- Add edge cases or extra test cases
- Fix typos or bugs

Thank you for helping make this the best daily LeetCode solutions repo! 🚀
